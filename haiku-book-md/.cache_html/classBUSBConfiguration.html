Detailed Description

Represents one of possibly multiple configurations a device might have.

The only way to get a valid object is through BUSBDevice::ConfigurationAt() or BUSBDevice::ActiveConfiguration().

BUSBConfiguration provides further access into the configuration by providing CountInterfaces() and InterfaceAt() to retrieve BUSBInterface objects.
