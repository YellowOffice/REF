Returns the routes of family type in interfaceName that are not filtered by filterFlags into routes.

Parameters
[in]familyThe address family. See the POSIX header file sys/socket.h for the address families.
[in]interfaceNameThe network interface name.
[in]filterFlagsFlag mask to filter out routes. See the POSIX header file net/route.h for the valid route flags.
[out]routesA BObjectList of BNetworkRoute to store the found routes.
