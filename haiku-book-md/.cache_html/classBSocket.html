◆ Accept()

status_t BSocket::Accept ( BAbstractSocket *&  _socket)
virtual

Accepts an incoming connection to this socket and initializes _socket to that remote endpoint.

This method extracts the first connection from the pending incoming connections' queue and fills _socket with the peer's information.

Return values
B_OKThe connection was accepted and the other object was initialized with the peer's information.
B_NO_MEMORYNot enough memory to allocate for the other socket object.
-1Failure to accept the incoming connection.
Since
Haiku R1

◆ Bind()

status_t BSocket::Bind ( const BNetworkAddress &  peer,
bool  reuseAddr = true 
)
virtual

Assigns a local address peer to this socket.

If reuseAddr is true, it should allow the reuse of the local address.

If the binding is successful, the object is left in a bound state.

Parameters
[in]peerThe local address to be bound to this socket object.
[in]reuseAddrWhether the reuse of local addresses should be allowed in non-zero requests.
Return values
B_OKBinding was successful.
EADDRINUSEThe specified address is already in use and reuseAddr is false.
EADDRNOTAVAILThe specified address is not available from the local machine.
EAFNOSUPPORTThe specified address is not of a family address accepted by the socket.
Since
Haiku R1
