Detailed Description

Abstract class to implement to watch for devices that get attached or removed from the USB bus.

The roster subclass must implement the pure virtual hooks DeviceAdded() and DeviceRemoved().

◆ DeviceAdded()

status_t BUSBRoster::DeviceAdded ( BUSBDevice *  device)
pure virtual

Hook method called when a new device gets attached to the USB bus.

The hook is called with an initialized BUSBDevice object. If you return B_OK from your hook the object will stay valid and the DeviceRemoved() hook will be called for it. Otherwise the object is deleted and DeviceRemoved() is not called.

Parameters
[in]deviceA BUSBDevice instance of the device attached.

◆ DeviceRemoved()

void BUSBRoster::DeviceRemoved ( BUSBDevice *  device)
pure virtual

Hook method called when a device gets detached from the USB bus.

The device object gets invalid and will be deleted as soon as you return from the hook so be sure to remove all references to it.

Parameters
[in]deviceA BUSBDevice instance of the device removed.
